# Архитектура

Схема показывает, **что** построено. Этот документ объясняет, **почему** именно так.

## Требования

Три требования, из которых следуют все решения ниже:

- клиенты обращаются к платформе из интернета;
- данные клиентов чувствительные;
- компания готовится к SOC 2.
