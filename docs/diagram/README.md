# Диаграмма

| Файл | Что это |
|---|---|
| `secure-saas-wide.drawio` | исходник, открывается в [app.diagrams.net](https://app.diagrams.net/) |
| `secure-saas-wide.png` | экспорт для вставки в README |

После правки исходника картинку нужно пересобрать: **File → Export as → PNG**, в поле **Size** выбрать **Diagram**, Zoom 200%.

Обозначения на схеме: сплошная линия — поток трафика, пунктир — ключи, секреты и сбор событий, рамка — зона доверия. Направление стрелки показывает, кто инициирует соединение.
