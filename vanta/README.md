# Автоматизация соответствия: Vanta

Vanta подключается к облачному аккаунту ролью только на чтение, периодически опрашивает ресурсы и сверяет их состояние с контролями выбранного фреймворка. Вместо ручного сбора доказательств раз в квартал соответствие видно непрерывно.
